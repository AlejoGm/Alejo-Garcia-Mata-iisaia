# Frontend

- Primero el celular: una columna, botones de al menos 48 px y acciones de carga al alcance del pulgar.
- Todo lo asíncrono muestra estado de carga y de error.
- Texto que viene de la API se inserta con `textContent`, nunca con `innerHTML`.
- `localStorage` siempre dentro de `try/catch`.
- Los pesos se muestran en la unidad del perfil; a la API van siempre en kg.
